The 3-Layered Defense System.

Our proprietary citation guardrail enforces absolute data purity. If a claim isn't in your curated project corpus, Lumen refuses to cite it.

1. Preventive

UI blocks and actively warns the user when attempting to save papers with "low" AI-relevance scores to the project corpus.

2. Detective

Matrix auto-tagging visually highlights rows where AI extraction confidence is low, enabling 1-click removal of bad data.

3. Protective

Backend Hybrid RAG explicitly drops DB records flagged as irrelevant. Bad data never reaches the final LLM report step.
